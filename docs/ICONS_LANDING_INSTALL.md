# ICONS Landing Page — Install

1. **Assets** ship in the theme (`assets/icons-look-01…24.webp`). Nothing to upload.
2. **Create the page:** Admin → Online Store → Pages → Add page ("ICONS"). In _Theme template_, choose **page.icons**. Save.
3. **Klaviyo:** open the theme editor on the ICONS page → the _ICONS Lookbook_ section → set:
   - **Klaviyo public API key** = your site/public key (company id).
   - **Klaviyo list ID** = the `ICONS – Launch Notify` list id.
     (If these were pre-filled during build, verify them.)
4. **Test:** submit the form with a test email; confirm the profile appears on `ICONS – Launch Notify` in Klaviyo.
5. **Copy:** all hero/subscribe/footer text is editable in the section settings — no code changes needed.

The grid, hero, and form honor reduced-motion and are responsive (2/3/4 columns). No prices, names, or buy buttons — mystery tease by design.
